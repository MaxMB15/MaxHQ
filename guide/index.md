# MaxHQ guide

How to do things in MaxHQ, page by page. The dispatcher answers how-to questions from this guide, so it matches the version you run.

## The guide's pages
<!-- id: index/pages -->

Each page covers one part of MaxHQ in short, task-shaped sections. Start with Getting started if MaxHQ is new to you.

- [Getting started](getting-started.md): what MaxHQ does, a tour of its window, and your first agent.
- [Agents and the composer](agents-composer.md): starting agents, talking to them, answering them and keeping track of many.
- [The dispatcher](dispatcher.md): asking for work in plain words, changes it makes and can undo, plans you confirm, and how-to questions.
- [Projects and workspaces](projects.md): projects, their settings, workspaces in containers and pull requests.
- [Devices and links](devices.md): adding devices, maxd, links between devices and each device's settings.
- [Local models](local-models.md): Local agents on your own hardware or a server you pick, and the Local models page.
- [Phones](phones.md): pairing an iPhone, what the phone app does and how pushes reach it.
- [Notes](notes.md): notes in Markdown for you and a project's agents.
- [Terminals and ! commands](terminals.md): terminals beside an agent and commands from the composer.
- [Ports and forwards](ports.md): ports agents listen on and forwarding them to this Mac.
- [Skills](skills.md): the skill library, global skills and each project's skills.
- [Scheduled tasks](scheduled-tasks.md): prompts on a schedule, from a webhook or on GitHub events.
- [Notifications](notifications.md): alerts, sounds, the Dock badge and phone pushes.
- [Permissions](permissions.md): what agents may do without asking, and how far agent tools go.
- [Updates](updates.md): keeping the app, maxd and the agent CLIs up to date.
- [Settings](settings.md): every Settings page and what its labels do.
- [Keyboard shortcuts](shortcuts.md): every key MaxHQ listens for.
- [Troubleshooting](troubleshooting.md): devices that won't connect, expired sign-ins, limits and stuck agents.

## Ask the dispatcher
<!-- id: index/ask -->

Type a question such as "where do I turn off sounds?" in the dispatcher box. It searches this guide, answers in a few steps and links to the view that has the setting.

Click the link in its answer to open that view, such as a Settings page, an agent or a note. See [The dispatcher](dispatcher.md) for what else it does.
